# Weight-Tracker

体重・体脂肪率を記録して、週平均・月平均と FFMI の推移を見るための1枚もののページ。

- **データはブラウザの中（localStorage）にだけ保存される。**サーバーへは送らない
- タニタ ヘルスプラネットのデータを、iOS ショートカット経由で取り込める
  （ショートカットが API を叩き、結果の JSON を URL フラグメント `#hp=` で渡す。
  フラグメントは仕様上サーバーへ送信されない）
- 身長・上限・目標は「設定」で入れる。既定値は一般的な値が入っているだけ

## 使い方

ページを開いて、日付・体重・体脂肪率を入れるだけ。
iPhone なら Safari の共有メニューから「ホーム画面に追加」で全画面のアプリになる。

## 中身

`index.html` 1ファイル。外部ライブラリ・CDN を使っていないので、
ダウンロードしてローカルで開いても同じように動く。
